# Nexus System

O **Nexus System** é um aplicativo mobile desenvolvido com o objetivo de facilitar o gerenciamento de projetos e tarefas, permitindo que os usuários organizem suas atividades, acompanhem seu progresso e tenham uma visão geral de sua produtividade em um único lugar.

O projeto foi desenvolvido utilizando **React Native e Expo**, com foco em uma interface intuitiva, organizada e adaptada para dispositivos móveis.

## Funcionalidades

- **Login e Cadastro:** telas de acesso e criação de conta.
- **Home:** painel inicial com visão geral dos projetos e das tarefas.
- **Gerenciamento de Projetos:** criação, edição, organização e exclusão de projetos.
- **Kanban:** organização das tarefas em três etapas: A Fazer, Em Andamento e Concluído.
- **Gerenciamento de Tarefas:** criação, visualização, edição e exclusão de tarefas.
- **Métricas:** acompanhamento de indicadores, gráficos e desempenho das atividades.
- **Busca:** pesquisa de projetos e tarefas.
- **Perfil:** visualização e edição das informações do usuário e preferências do aplicativo.

## Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- React Navigation
- AsyncStorage
- Git e GitHub

## Objetivo do projeto

O principal objetivo do Nexus System é oferecer uma ferramenta prática para organizar projetos e atividades, facilitando o acompanhamento de prazos, prioridades e etapas de execução.

A aplicação foi estruturada considerando uma futura integração com **Spring Boot e MySQL**, permitindo evoluir o armazenamento local para uma arquitetura com backend e banco de dados.

## Desenvolvimento

O Nexus System é um projeto acadêmico desenvolvido em equipe, como parte dos estudos de Análise e Desenvolvimento de Sistemas, envolvendo conceitos de desenvolvimento mobile, componentização, navegação entre telas, gerenciamento de estados e persistência de dados.
